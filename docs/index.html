      ほかのブラウザ・機種に引き継ぐ

      データはブラウザごとに別々に保存されます。iPhone では、Safari と「ホーム画面に追加」したアプリも別々なので、ホーム画面から開くと最初の状態に見えます。ここで、いまのデータを移せます。

      ① 移す前の画面で（例: Safari）

      ② 移した先の画面で（例: ホーム画面のアプリ）

      この画面にあるデータは消えず、引き継いだ分と合わせて残ります。パスコードは引き継がれないので、必要ならこの画面で設定し直してください。

      通信を使わずに移す（コピー＆貼り付け）

      同じスマホの中なら、コピー＆貼り付けでも移せます。① 移す前の画面で「データをコピー」→ ② 移した先の画面でこの欄に貼り付けて「読み込む」。

      学生の設定

      パスコード

      この端末に保存するデータに鍵をかけます。設定しなくても使えます。

      • 守れるもの：このブラウザに保存したサブスクの一覧と設定。パスコードから作った鍵で暗号化（AES-256）するので、スマホを人に貸したときなどに中身を見られません。
      • 開くたびに求める：オンにすると、アプリを開くたびに入力します。オフなら、この端末では入力を省けます。
      • 忘れたら元に戻せません：パスコードはどこにも送らず、アプリの作者も知らないため、再発行できません。設定する前にバックアップを書き出しておくと安心です。
      • 書き出したバックアップも同じパスコードで暗号化されます（引き継ぎコードとは別のものです）。

      みんなのサブスク・人気ランキング

      このアプリを使っている人の間でよく使われているサブスクを、「概要」と追加画面に表示します。

      参加すると、サブスクを追加したときにどのサービスかだけを匿名で1つ数えます（同じサービスは1回だけ）。金額・支払日・メモなど、ほかの情報は送りません。

      友だちにすすめる

      このアプリのリンクを送れます。データはそれぞれのブラウザに保存されるので、あなたの登録内容が友だちに見えることはありません。

      プライバシー

      • 登録した内容（名前・金額・支払日・支払い方法・メモ）は、いま使っているブラウザの中にだけ保存されます。アカウント登録はありません。
      • ほかの場所には何も送信しません。
      • 外に送るのは次の3つだけです。送り先は Google の Firebase で、アカウントやメールアドレスは使わないため、誰が送ったかはデータに残りません。
        • 人気ランキングに参加しているとき：追加したサービスの種類（例: Netflix）を1つ数える情報
        • 「みんなのサブスクに公開」を選んで保存したとき：そのサブスクの名前・カテゴリ・金額・支払い周期
        • 引き継ぎコードを発行したとき：コードで暗号化したデータ（24時間で期限切れ。受け取ると消えます）
      • カード番号・パスワードなどを入力する欄はありません。支払い方法は「楽天カード」のような呼び名だけで十分です。
      • フォントや画像も外部から読み込みません。

      価格データ

      よく使うサービスの価格は毎月1日に調べ直して更新します。更新されると、登録中のサブスクと金額が違うものを「お知らせ」に表示します。実際の請求額は、決済方法や加入時期によって変わることがあります。
