# サブスク通帳

大学生向けのサブスク管理アプリです。ブラウザで開いて、ホーム画面に追加して使えます。

- 動画・音楽・ゲームの月パス・コンタクトの定期便など、約100サービスの参考価格を収録（毎月1日に更新）
- 学割・卒業後に上がる料金の試算、プランの比較、見直しの案
- 支払日カレンダー、予算、CSV・カレンダー用ファイルの書き出し

## データの置き場所

- 登録した内容は、使っているブラウザの中にだけ保存されます。このリポジトリやサーバーには送られません。
- 「スマホとPCで同期」をオンにしたときだけ、パスコードで暗号化したデータを、あなた自身の GitHub アカウントの非公開 Gist に置きます。Gist にあるのは暗号文だけで、パスコードがないと読めません。
- 同期に使う GitHub のトークンは、そのブラウザの中に保存されます。権限は「gist」だけにしてください。

## ファイル

- `app/index.html` … アプリ本体（claude.ai 版と共通）
- `app/catalog.js` … 価格カタログ。毎月の更新はこのファイルだけを書き換えます
- `build_site.py` … `app/` から公開用の `docs/` を作るスクリプト（`python build_site.py`）
- `docs/` … GitHub Pages で公開されるファイル（手で編集しない）
