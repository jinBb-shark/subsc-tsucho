# サブスク通帳

大学生向けのサブスク管理アプリです。ブラウザで開いて、ホーム画面に追加して使えます。

- 動画・音楽・ゲームの月パス・コンタクトや食事の定期便など、100以上のサービスの参考価格を収録（毎月1日に更新）
- 学割・卒業後に上がる料金の試算、プランの比較、見直しの案
- 支払日カレンダー、予算、CSV・カレンダー用ファイルの書き出し
- みんなのサブスク（一覧にないサブスクを公開して共有）と人気ランキング
- 引き継ぎコードで、ほかのブラウザ・機種にデータを移す（iPhone の Safari →「ホーム画面に追加」したアプリ など）

## データの置き場所

- 登録した内容は、使っているブラウザの中にだけ保存されます。アカウント登録はありません。
- 外（Firebase の Firestore）に送るのは次の3つだけです。アカウントやメールアドレスは使いません。
  - 人気ランキングに参加しているとき（設定でオフにできます）: 追加したサービスの id を1つ数える情報
  - 「みんなのサブスクに公開」を選んだとき: そのサブスクの名前・カテゴリ・金額・支払い周期
  - 引き継ぎコードを発行したとき: コードから作った鍵で暗号化したデータ（24時間で期限切れ。受け取ると削除）
- 支払日・支払い方法・メモ・利用頻度は、どこにも送りません。

## ファイル

- `app/index.html` … アプリ本体
- `app/catalog.js` … 価格カタログ。毎月の更新はこのファイルだけを書き換えます
- `app/config.js` … 公開用の設定（アプリのURL・Firebase の接続先）
- `app/og.png` … リンクを共有したときに表示される画像
- `firestore.rules` … Firestore のルール（Firebase コンソールに貼り付けて使う）
- `build_site.py` … `app/` から公開用の `docs/` を作るスクリプト（`python build_site.py`）
- `docs/` … GitHub Pages で公開されるファイル（手で編集しない）

## Firebase の設定（みんなのサブスク・人気ランキング・引き継ぎコードを使うとき）

`app/config.js` の `firebase` が空のあいだは、これらの機能は表示されません（コピー＆貼り付けでの引き継ぎは使えます）。

1. https://console.firebase.google.com/ で新しいプロジェクトを作る（Google アナリティクスはオフでよい）
2. ［構築］→［Firestore Database］→「データベースを作成」。ロケーションは `asia-northeast1`（東京）、「本番環境モード」で開始
3. ［ルール］タブに `firestore.rules` の中身を貼り付けて「公開」
4. （任意）［Firestore］→［TTL］で、コレクション `transfer` のフィールド `expireAt` に TTL ポリシーを作ると、期限切れの引き継ぎデータが自動で消えます
5. プロジェクトの設定（歯車）→「マイアプリ」でウェブアプリ（</>）を追加し、表示される `apiKey` と `projectId` を `app/config.js` に書く
6. `python build_site.py` を実行して、`app/config.js` と `docs/` をコミット・push

`apiKey` は公開してよい値です。読み書きできる範囲は `firestore.rules` で制限しています。
